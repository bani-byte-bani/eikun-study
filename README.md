# eikun-study

中学の自動採点付き練習問題集（静的サイト）。

## 使い方

`index.html` をブラウザで開くと、範囲・問題集をリストから選べます。問題集を選ぶと、その場で回答・自動採点ができるページに移動します。

## 構成

- `index.html` — 範囲・問題集を選ぶハブページ
- `style.css` — 共通スタイル
- `quiz-engine.js` — 共通の採点エンジン（進捗バー、Enterキーでの入力欄移動、採点、結果パネル表示、成績の保存、印刷用シートの生成）
  - 採点後は正解・不正解にかかわらず、答え・解説・雑学をすべて表示する

## 成績の保存

採点した点数・最高得点・採点日時と、入力した解答がブラウザに保存されます。同じ問題集をもう一度開くと解答が復元され、続きから取り組めます。

- 保存先は `localStorage`（キー: `eikun-study-records`）。
- プライベートモードなどで `localStorage` が使えない場合は Cookie（`eikun_study_records`、有効期限180日）に自動でフォールバックする。Cookie は容量が小さいため、その場合は解答内容は保存されず点数の要約だけが残る。
- サーバーには何も送信されず、記録はそのブラウザの中だけに保存される。
- 消したいときは、各問題集ページの「記録を消去」ボタン、またはトップページの「学習記録をすべて消去」ボタンを使う。
- `quizzes/g1-1st-term-math.html` — 中1 第1学期末テスト対策 数学（正負の数・文字と式、30問、偏差値67レベル）
- `quizzes/g1-summer-review-math.html` — 中1 夏休み確認問題 数学（正負の数・文字と式・一次方程式、24問、偏差値65レベル）

- `quizzes/g1-summer-review-science.html` — 中1 夏休み確認問題 理科（植物・物理現象・物質・力、24問、偏差値65レベル）

## 問題量（ふつう／しっかり／ガリ勉）

各問題には優先度が付いていて、スコアバーのボタンで出題する量を3段階から選べます。

| 表示 | 出題する優先度 | 目安 |
| --- | --- | --- |
| ふつう | 必修（pri 1）のみ | 基準の問題数 |
| しっかり | 必修＋標準（pri 1〜2） | ふつうの約1.5倍 |
| ガリ勉 | 必修＋標準＋発展（pri 1〜3） | ふつうの約2倍 |

- 選んだ量は問題集をまたいで記憶され、**画面の出題にも印刷にも同じように反映**されます。
- 最高得点は同じ問題量どうしで比べます（ふつうの満点と、ガリ勉の満点は別々に記録されます）。
- 9月診断テスト対策の5教科は、ふつう25問 / しっかり38問 / ガリ勉50問。
  それ以前に作った問題集は全問が必修（pri 1）なので、どの量を選んでも問題数は変わりません。

## 印刷（紙のプリント）

各問題集ページの「問題を印刷」「解答・解説を印刷」ボタンから、紙で使えるプリントを出力できます。

- **問題を印刷** — 名前・日付・得点の記入欄と、各問の解答記入欄（罫線）が付いた問題用紙。
- **解答・解説を印刷** — 各問の答え・解説・雑学を載せた解答用紙。
- ブラウザの印刷（Ctrl+P / ⌘P）でも問題用紙が出力される。
- A4縦・1問がページ途中で分断されないレイアウト。画面用のヘッダーやボタン、入力欄は印刷されない。

## 問題集の追加方法

問題カードは `quiz-engine.js` がデータから描画するので、**HTMLに問題を書く必要はありません**。

1. `quizzes/` に新しいHTMLファイルを作成し、既存の `g1-sep-exam-*.html` をコピーする
   （`<main id="quiz-main">` と結果パネルだけを残し、`<link>`/`<script src>` はそのまま流用する）。
2. 末尾の `<script>` 内で `sections` と `questions` を定義し、`initQuiz(questions, sections)` を呼ぶ。

```js
const sections = [
  { label: 'A', title: 'セクション名', hyoka: ['chi', 'shi'] },
];
const questions = [
  { num: 1, sec: 'A', pri: 1, diff: 'A',      // pri 1=必修 2=標準 3=発展、diff B/A/S＝★の数
    text: "問題文（HTMLを書ける）",
    hyoka: 'chi', answer: '正答例', hint: '解説', trivia: '雑学',
    check: v => qAccept(v, ['正答例', '別解']) },
];
initQuiz(questions, sections);
```

- `num` は要素IDと解答の保存キーになる安定した識別子。あとから問題を足しても、既存の `num` は変えないこと
  （画面と紙に出る通し番号は表示位置から自動で振り直されるので、`num` が連番でなくても問題ない）。
- `wide: true` で入力欄を広く、`placeholder: '例: …'` で入力例を出せる。
- 新しい問題集は、各セクションで必修:標準:発展をおよそ 2 : 1 : 1 の割合で用意すると、
  ふつう／しっかり（1.5倍）／ガリ勉（2倍）がきれいにそろう。
3. `index.html` の `.set-list` に新しい `.set-card` を追加してリンクする。
